# 📝 TO DO LIST: FUTURE SYSTEM EXPANSIONS

## Pursuit & Detection System
- Implement a Sith Predator (or lore-appropriate hunter) that actively hunts the player based on actions.
- Using Force powers, especially dark side abilities, increases detectability.
- Combat moderately increases detection; stealth actions keep you hidden.
- Disguises reduce detection.

## Disguise & Suspicion Mechanics
- Add disguises: civilian clothes, stormtrooper armor, merchant garb, etc.
- Each disguise reduces detection and grants access to different factions.
- NPCs become suspicious if you act strangely (Force use, sneaking, theft near Imperial/Hutt factions).
- High suspicion triggers alarms and hostile responses.

## Faction System & Dynamic World
- Add factions: Imperial, Rebel, Hutt Cartel, Settlers.
- Player actions affect reputation with each faction.
- Hostile factions attack on sight; friendly factions may help.
- Factions can fight each other, creating dynamic battlefield encounters.

## Physical Force System
- Force powers interact with the environment (e.g., Force Push moves objects/enemies, creates barriers, triggers effects).
- Make the environment a tactical weapon.

## Corruption & Moral Choices
- Using dark side powers increases corruption.
- Low corruption: NPCs wary; moderate: animals avoid you; high: light side powers lock, dark side powers strengthen.
- Create meaningful choices about using corrupting powers.

## Dynamic Lightsaber Building
- Find lightsaber parts to build custom sabers.
- Different crystals, hilts, emitters = unique combat styles (double-bladed, shoto, standard, etc.).
- Saber becomes an expression of playstyle.

## Enhanced User Interface
- Add UI elements for pursuit level, corruption meter, faction status, disguise info.
- New keyboard controls for echo activation, disguise management, force power selection.
